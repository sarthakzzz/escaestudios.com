What we do

Professional audio processing with an interface you can understand at a glance.

Audio effect plugins

Distortion, EQ, compression, delay, reverb, modulation, granular and mastering effects that run inside your music software (DAW).

Hand-made interfaces

Every plugin is drawn as a small felt world. Each object on screen is a real control, so you learn the plugin by playing with it.

Built for macOS

Audio Unit (AU) and VST3 formats for Logic Pro, Ableton Live, FL Studio, Cubase, Reaper, Studio One and other hosts on Apple silicon and Intel Macs.

Support from the makers

Questions go straight to the team that builds the plugins, at hello@escaestudios.com.
